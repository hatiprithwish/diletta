How do I add a custom field to the Fire safety register?

You can add it from the register's settings. You need the Register admin role.

  1. Open the register, then Settings → Fields.1
  2. Choose Add field, pick a type such as Date or Dropdown, and name it.1
  3. Turn on Required if every record needs a value. Existing records stay valid until they're next edited.2
